## 为什么要更新 Quickshell

现有 Quickshell 的 Polkit 接口只有提交与取消整项授权，缺少重开当前认证会话的能力。新包保持本机当前源码提交 `2b4501a282689792b62e94f3fb30d8f512324fe6`，增加安全的 `restartAuthentication()`，版本为 `0.3.2.r7.g2b4501a-2`。

这个方法保留原应用的授权请求、cookie 和所选管理员；断开旧 Session 回调后才取消旧会话，避免旧信号影响新会话。返回不会直接发送 y，也不直接启动相机。用户再次选择“使用人脸”后才同意扫描。若当前运行时没有新 API，插件保留密码路径并隐藏无法完成的返回动作。

配方、补丁、构建与原生测试说明见 `modules/face-auth/packaging/quickshell-polkit-restart/README.md`。安装是对本机 Quickshell 包的一次更新，不能只复制 UI 就认为 Polkit 返回功能完整启用。

## 安装

在桌面未锁定、没有未完成授权对话时执行；保留当前终端。此轮已经构建的本机包位于下列目录，二进制包本身不提交 Git。

若工具打开的终端提示 `The "no new privileges" flag is set`，sudo 尚未进入密码验证。请从 Omarchy 应用启动器手动打开新终端再执行，不能通过重新输入密码解决。`grep NoNewPrivs /proc/self/status` 应显示 `0`；不修改系统隔离设置来绕过该限制。

二进制包不提交到 GitHub。先按当前系统版本审阅配方；仅在版本匹配后构建。以下步骤从仓库根目录逐行执行：

```bash
cd modules/face-auth/packaging/quickshell-polkit-restart
makepkg -s
sudo pacman -U ./quickshell-0.3.2.r7.g2b4501a-2-x86_64.pkg.tar.zst
cd ../../../..
./install.sh plugin-ui
./install.sh sudo-face
omarchy restart shell
```

`plugin-ui` 更新用户锁屏/Polkit 克隆并备份旧目录；`sudo-face` 更新终端提示与目录中的语言资源，沿用既有 PAM 管理块。不要删除人脸模型或重复录入来更新 UI。

配方仅适用于本机对应源码提交，不应用来降级其他用户较新的 Quickshell。

## 本机复测：建议顺序

记录每项“通过/失败/未触发”，失败附发生时间和简短现象，不发送真实密码。

1. **A1 密码兜底**：运行 `omarchy system lock`，先选择密码并正常解锁；确认更轻的掩码、焦点和提交均正常。
2. **A2 锁屏往返**：锁屏后进入密码页，输入几位但不提交；点击“返回人脸验证”。密码应清除，回到人脸选择且不立即扫脸；再点“使用人脸”尝试识别。
3. **A3 输入停顿**：密码页输入部分字符，暂停至少 70 秒；完整输入但不回车再暂停一次。两种情况均不应自动熄屏。清空后闲置，应重新开始 60 秒计时。
4. **A4 关屏保持**：点左下角“关闭屏幕”，不继续操作，重复 5 次；记录是否自行亮屏。另做一次刚移动鼠标后立即关屏。新按键/点击仍应能唤醒。
5. **A5 清理与唤醒**：输入部分密码并打开显隐，主动关屏，等待至少 2 秒再唤醒。旧内容不应保留，显隐恢复隐藏；约 1.5 秒后一次识别，无反复扫描。休眠恢复另测一次。
6. **T1 终端**：运行 `sudo -k -v`，先选 n 验证密码，再运行并选 y。只有 y 后出现示意并启动识别；缩窄终端后仍有可读提示。中文、英文各观察一次即可。
7. **G1 图形往返**：运行 `pkexec /usr/bin/id`，先选密码，输入几位但不提交，点返回人脸。原命令应继续等待，身份不变；选择人脸成功才输出 root 身份。另测一次人脸未识别后返回，再次使用人脸。
8. **G2 取消与真实应用**：单独重新触发 pkexec 并取消，应不输出 root 身份；再选择一个确实需要管理员认证的真实应用动作，测试密码/人脸。不要把授权缓存未弹窗计为通过。

多屏时在副屏重复 A2、A4、G1；不同屏幕的输入清理应一致。先确认密码兜底后再做关屏/休眠，减少难以定位的变量。

## 回退

UI 和 sudo 安装各有快照。在该次安装使用的备份根下运行 `./scripts/restore.sh`，分别选择对应快照；恢复哪一步只撤销该快照记录的文件，不是一份快照删除所有入口。桌面未锁定时再重启 shell。

本机原 Quickshell 包保留在 pacman 缓存。需要撤销原生补丁时，可安装该原包，再恢复旧 UI：

```bash
sudo pacman -U /var/cache/pacman/pkg/quickshell-0.3.2.r7.g2b4501a-1-x86_64.pkg.tar.zst
omarchy restart shell
```

若之后系统已升级到不同版本，先核对实际缓存与版本，不照抄旧路径降级。
