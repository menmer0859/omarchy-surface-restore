# 本机验收问题修复执行清单

用户已在 2026-10-22 授权按综合审阅建议修改、构建并测试。范围为现有 Surface Laptop 5；参考原目录 docs/acceptance-issues.md 的 ACC-001～007，以及 docs/research/surface-family-research-review.md。本轮不扩大机型支持名单。

## 约定与实现边界

- 保留手动锁屏不扫描、实际唤醒后 1.5 秒单次扫描、密码兜底、中英文和明确 sudo/Polkit 同意。
- 空闲锁屏采用 30 秒；选择空密码页面采用 60 秒。密码非空或正在认证时停止自动熄屏，输入/切换重新计时。显式关屏仍立即生效，清理未提交内容。实际熄屏/休眠后恢复为新的锁屏唤醒流程，密码原文不保留。
- 序列化唤醒与关屏命令，过滤关屏操作之后的短时被动指针事件；旧的唤醒命令不得在新关屏命令之后执行。
- 用较小的密码掩码改善密度，隐藏状态不泄露输入字符；密码显隐操作也算活动。
- 密码页的人脸返回按钮只返回明确的方式选择。Polkit 必须保留原受保护请求和管理员身份，不能把 y 发给密码挑战，不能以取消原动作伪装返回。当前 Quickshell 缺少重开 Session API，按真实能力增加补丁和新版本包，旧运行时不显示无效入口。
- 终端在明确 y/Y 后显示紧凑静态相机示意，中英文和窄/简化终端回退；保持同意和失败回退语义。
- 硬件相机释放与 UI 结束分别记录；现有 Howdy 子进程中止限制不以 UI 超时冒充解决。

## 重点回归

新关屏不能被旧 wake 完成或后续鼠标事件撤销；部分密码和未提交完整密码不触发自动熄屏；真正 blank 后内容与显隐状态清空；密码切人脸需明确入口；Polkit 重开不取消原应用请求且丢弃旧 Session 信号；终端拒绝不显示相机图、不访问摄像头；减少动态效果与中英文保持可用。
